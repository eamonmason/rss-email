## 2. Key Technical Concepts

- **CDK Pipelines self-mutation deadlock**: The Synth stage CodeBuild command is baked into the *deployed* pipeline. Fixing that command only takes effect after UpdatePipeline (self-mutate), which runs *after* Synth. If Synth fails, self-mutate never runs → fix never applies → deadlock.
- **promptfoo dependency isolation**: Moving promptfoo to `eval/package.json` (its own island) keeps the root `package-lock.json` clean of the `mongodb/gcp-metadata` transitive tree that breaks `npm ci` under npm 10.
- **npm 10 vs npm 11 optional peer dep behaviour**: npm 10 (Node 20 in CodeBuild) fails `npm ci` when `mongodb@7.2.0`'s optional peer `gcp-metadata@^7.0.1` is resolved to `8.x`. npm 11 (local Node 24) tolerates this.
- **Reddit rate-limiting root cause**: `ThreadPoolExecutor(max_workers=5)` fires 5 Reddit requests concurrently from one IP → instant 429. An HTTPS 429 also triggers the SSL-fallback handler (2 more requests) + outer retry 3× ≈ 9 requests per feed.
- **Host-aware throttle**: Serialise requests to rate-sensitive hosts using a per-host `threading.Lock` + monotonic timer, spacing starts by at least `RATE_LIMITED_HOSTS[key]` seconds.
- **promptfoo custom Python provider** running real `brief_generator.synthesize()` against fixture digest JSON.
- **CDK Pipelines V2** with self-mutate stage; `CodeBuildStep('Synth')` with baked-in `commands`.

```python
RATE_LIMITED_HOSTS = {"reddit.com": 8.0}
_STATUS_CODES_NO_FALLBACK = (304, 403, 429)
_throttle_registry_lock = threading.Lock()
_host_locks: Dict[str, threading.Lock] = {}
_host_last_start: Dict[str, float] = {}

def _rate_limited_host_key(url: str) -> Optional[str]:
    host = (urllib.parse.urlsplit(url).hostname or "").lower()
    for key in RATE_LIMITED_HOSTS:
        if host == key or host.endswith("." + key):
            return key
    return None

def _throttle_host(url: str) -> None:
    key = _rate_limited_host_key(url)
    if key is None:
        return
    with _throttle_registry_lock:
        lock = _host_locks.setdefault(key, threading.Lock())
    with lock:
        wait = RATE_LIMITED_HOSTS[key] - (time.monotonic() - _host_last_start.get(key, 0.0))
        if wait > 0:
            logger.debug("Throttling %s for %.1fs to respect %s rate limit", url, wait, key)
            time.sleep(wait)
        _host_last_start[key] = time.monotonic()
```

def test_rate_limited_host_key(self):
    self.assertEqual(_rate_limited_host_key("https://www.reddit.com/r/aws/top/.rss?t=month"), "reddit.com")

    self.assertIsNone(_rate_limited_host_key("https://notreddit.com.evil.test/x"))

@patch("rss_email.retrieve_articles.time.sleep")
def test_throttle_spaces_requests(self, mock_sleep):
    # pylint: disable=protected-access
    rss_email.retrieve_articles._host_last_start.clear()
    self.addCleanup(rss_email.retrieve_articles._host_last_start.clear)
    url = "https://www.reddit.com/r/aws/top/.rss?t=month"
    _throttle_host(url)
    mock_sleep.assert_not_called()
    _throttle_host(url)
    mock_sleep.assert_called_once()
    waited = mock_sleep.call_args[0][0]
    interval = rss_email.retrieve_articles.RATE_LIMITED_HOSTS["reddit.com"]
    self.assertGreater(waited, 0)
    self.assertLessEqual(waited, interval)
